# Organization

[Introduction](Introduction.md)

Self-organization is how copies of the same model arrange their work together. We study three decisions:

| Dimension | Decisions |
| --- | --- |
| Communication | Who exchanges information, when, and through which shared artifacts. |
| Resources | How to divide compute and time between subtasks. |
| Reorganization | When to change the plan, merge work, or stop. |

Agents leverage scripts, files, and messages. The training target includes learning to construct the coordination tools themselves.

## One shared model

All agents run the same checkpoint, with their own context and task history.
[Control experiments](Experimental-controls.md) test the benefit of interaction.
